These are old scripts and small projects. Most predate my current work and are kept here mainly because people still find them through search.

- [ev3py](https://github.com/thiagomarzagao/ev3py): a Python module for interacting with LEGO Mindstorms EV3 bricks using the native firmware.
- [CATMATfinder](https://github.com/thiagomarzagao/catmatfinder): an NLP app that suggests likely government-procurement categories from a Portuguese product description.
- [Wordscores in Python](/2013/06/10/wordscores-in-python/): an implementation designed to work with corpora too large to fit in memory.
- [Fightin' Words in Python](/2013/06/24/130/): an implementation of the Monroe, Colaresi, and Quinn algorithm.
- [FitbitBot](https://github.com/thiagomarzagao/fitbit): a small bot that automated bulk downloads from Fitbit's old interface.
- Scripts to [scrape](https://gist.github.com/thiagomarzagao/0288f7ec358caf40a554) and [parse](https://gist.github.com/thiagomarzagao/f5b78bd8a4bc874b9846) public-procurement data from Brazil's Federal District.

Replication code for older papers is linked from the [publication archive](/academics/archive/).
